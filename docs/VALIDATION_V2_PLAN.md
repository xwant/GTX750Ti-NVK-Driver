Эти данные созданы тестами и не относятся к GTX 750 Ti.

При первом checksum check обнаружено 17 несовпадений, уже присутствовавших в исходном project HEAD: все перечисленные архивные файлы, кроме `.patch`, потеряли последний байт `LF`. Для каждого проверено, что добавление ровно `b'\n'` даёт **исходный ожидаемый SHA-256**. Эти конечные переводы строки восстановлены; список `SHA256SUMS` не переписан под повреждённые файлы. Код и содержание исторических результатов при этом не изменены. Пробелы в последней строке исторического testlog сохранены ради точного совпадения с архивом; это известное исключение whitespace check, не ошибка нового кода.

Команды проверки доступны без GPU. Старые 11/11 CPU-тестов драйвера в `logs/` относятся к v0.1 и **не перезапускались** в данном этапе. Новый Mesa binary не выдаётся.
